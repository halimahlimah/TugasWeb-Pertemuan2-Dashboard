# Landing Page Pribadi — Tugas Pertemuan 1

## Isi tugas
Landing page pribadi menggunakan HTML5 semantik yang memuat:
- Tentang diri
- Hobi
- Pendidikan
- Kontak

## Kriteria yang dipenuhi
- Minimal 5 semantic tags: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`, `figure`.
- Struktur HTML5 valid.
- Form kontak memakai validasi HTML dan JavaScript.
- Elemen media berupa gambar profil SVG lokal.
- Accessibility: `alt`, label form, `aria-label`, `aria-labelledby`, `aria-describedby`, `aria-live`, dan skip link.
- Responsive untuk layar desktop dan mobile.

## Yang harus kamu ubah
Ganti:
1. `Nama Anda` dengan nama kamu.
2. `Universitas / Program Studi` dengan data pendidikan kamu.
3. Tahun pendidikan jika perlu.
4. Deskripsi tentang diri dan hobi sesuai kondisi sebenarnya.

## Cara menjalankan
Buka `index.html` langsung di browser.

## Untuk GitHub
Buat repository publik, upload `index.html`, `style.css`, dan `profile.svg`, lalu aktifkan GitHub Pages.
